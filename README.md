# KLCF Website

Website for Kuala Lumpur Christian Fellowship.

## Files

- `index.html` — page structure and content
- `style.css` — layout and responsive design
- `script.js` — mobile navigation and current year
- `klcf.jpg` — hero image (add your church photo to the repository)

## GitHub Pages

This project is designed as a static website and can be published with GitHub Pages from the `main` branch.
